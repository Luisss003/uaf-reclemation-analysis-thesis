# Methodology

Created 2 interpositioning functions that simply output addresses and values of heap chunks when allocated and freed. This info extraction will be important for building genrations/relationships.

# Main Findings

## Stick to signal-safe functions when interposing

`printf` will allocate its own memory, messing with the startup function and leading to debugging errors.

## Must Manually Estimate Used Bin for Freed Chunk

We must estimate what bin a chunk ends up in via heuristics. Without directly
analyzing allocator state, unable to determine for a fact where 

This should be easy for tcache and fastbin since:

1) Tcache replaces user mem with `stored_next = 0 ^ (free_user_addr >> 12)` (Safe Linking). So we can determine if the stored value looks like a safe NULL or a heap address.

2) Fastbin also has a predictable behavior.
