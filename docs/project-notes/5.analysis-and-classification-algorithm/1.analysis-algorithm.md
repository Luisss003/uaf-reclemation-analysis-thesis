# Analysis Algorithm

## What is this algorithm for?

The AA is what we will use to actually to turn our raw metrics and observations into facts about the execution. A small example; say we find these observations:

```
malloc -> address X, size 64
pointer p recv X
free(X)
malloc -> address X, size 64
input bytes written through X
load 8 bytes through p
```

Then with our analysis algorithm we must output something like:
1. first malloc -> allocation generation A1
2. p originated from A1
3. first free ended A1's lifetime, so start new generation on next malloc
4. second malloc = alloc generation A2, which happens to be the same size and addr as A1
5. p still carries provenance A1

## 

Therefore, we can make the following observations:
1. p is stale
2. accessed memory currently belongs to A2
3. A1's memory has been reclaimed



To make concrete claims, we need to them forward this to the classification algorithm.
