# Classification Algorithm

## What is this algorithm for?

The CA takes the output of our AA, and using rules we define, assisn meaningful categories. Using the output of the example in the analysis algorithm note, we could generate something like:

1) Temporal State: stale access

2) Reclamation State: reclaimed

3) Replacement relationship: A1 -> A2

4) Observed Operation: stale read

5) Attacker Data Relationship: 6/8 bytes attacker derived
