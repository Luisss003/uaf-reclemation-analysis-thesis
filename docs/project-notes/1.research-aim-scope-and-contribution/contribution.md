# Contributions

1) A dynamic model connecting stale pointer allocation identity with the 
   replacement allocation currently occupying the accessed region

2) A technique for measuring byte level overlap between stale accesses and 
   attacker derived replacement data.

3) A prototype implementation for source available C/C++ programs using glibc 
   and LLVM.

4) An empirical evaluation of the technique udner controlled and realistic UAF 
   executions.
